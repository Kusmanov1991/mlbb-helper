# Как обновить данные

Страница `index.html` собирается из файлов этой папки. Руками её не правим.

```bash
cd tools
python3 gen3.py      # героев, сборки, матчапы и статистику превращает в gen3_out.json
python3 build2.py    # вставляет данные и runtime.js в template.html и пишет ../index.html
node test.js         # быстрая проверка логики по всем линиям и режимам
```

## Что где лежит

- `mh.txt` — винрейт / пик / бан на Мифической чести: `slug|win|pick|ban`, по одному герою на строку.
- `roam.py`, `lanes2.py` — контрпики и сборки для роума, опыта и леса.
- `template.html` — разметка, стили, данные по золоту и миду, номер патча (строка `class="stamp"`).
- `gen3.py` — новые герои (`NEW`), линии героев (`LANE_IDS`), советы и сборки (`TIP`, `BUILD`, `OVR`).
- `build2.py` — правки разметки и русские названия героев (`RENAME`).
- `runtime.js` — вся логика страницы. Видимые вкладки — `TABS` (мид и лес спрятаны, их данные остались). Золото и опыт: прямые контрпики — `countersOf` (статистика ≥ +1 п.п. или контрпик по механике, кроме пар из `PATIENCE`), запасной список меты — `metaOf`. Роум — `roamRank`.
- `profiles.py` — описания героев золота и опыта (как играть за героя и против него, что докупить), метовые роумеры и ситуации для роума, исправленные сборки (`BUILD_FIX`), комбо и лайфхаки (`COMBO`): умения названы по кнопкам — 1-е, 2-е, 3-е умение и ульт.
- `matchups.py` — разобранные вручную пары «мой герой против врага» по всем линиям.
- `ru_official.txt` — официальные русские названия героев.

## Порядок обновления под новый патч

1. Обновить номер патча и дату в `template.html` (строка `stamp`).
2. Обновить `mh.txt` свежей статистикой Мифической чести.
3. Для героев, изменённых в патче: сверить механику с mlbbhub.com/heroes/<slug>, поправить `profiles.py`, `matchups.py` и сборки. Проверить, что восемь героев в `ROAM_META` всё ещё сильнейшие роумеры.
4. Добавить новых героев в `NEW` и `LANE_IDS` в `gen3.py`, русское имя в `RENAME`.
5. Собрать, прогнать `test.js`, закоммитить.

Источник данных: mlbbhub.com. Его нужно указывать на странице.
