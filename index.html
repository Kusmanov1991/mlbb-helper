Откуда данные. Цифры «+N п.п.» показывают, насколько винрейт героя вырастает в этом матчапе по ранговым играм (mlbbhub, патч 2.2.23; для части героев последние данные от патча 2.2.16a; матчапы посчитаны по всем рангам). Метка «по механике» значит, что измеренного преимущества на этой линии нет и герой подобран по набору умений. Метка «по винрейту» значит, что измеренного контрпика на этой линии нет и показан сильный герой патча.
Слепой пик. На золоте и миду в списке герои, против которых на их линии почти нет измеренных контрпиков, на роуме, линии опыта и в лесу все герои линии (показаны 12 лучших под состав). Оценка = винрейт героя на Мифической чести за 7 дней минус 50, плюс его преимущества и минус его слабости против отмеченных врагов, минус самый сильный контрпик с его линии, который ещё не в бане (враг может взять его позже). Учитываются только матчапы, по которым есть статистика, поэтому отметить можно не любого героя.
Баны. Винрейт и бан-рейт взяты по Мифической чести (25–49 звёзд) за 7 дней. Список отсортирован по угрозе = (винрейт − 50) + бан-рейт / 20. У героев, которых банят очень часто, винрейт посчитан по меньшему числу игр. Порядок драфта: пики идут змейкой 1-2-2-2-2-1, последний пик у команды, которая пикает второй.
Сборки. Базовый порядок закупки на всю игру, названия как в русской версии. Сборки Мии и Беатрис сверены с гайдами сезона 42. На роуме, линии опыта и в лесу сборки шаблонные, одна на тип героя: обязательно сверяй с рекомендуемыми в игре.
Значки. Кружки с буквами и значки предметов нарисованы для этой страницы: красный — физический урон, фиолетовый — магия, зелёный — защита, золотой — ботинки. Это не игровые иконки.
Прогноз. Шанс = 50% + половина разницы в среднем винрейте героев (Мифическая честь) + среднее преимущество в матчапах между командами. Учитываются только пары, по которым есть статистика. Итог ограничен диапазоном 15–85%. Прогноз не проверялся на реальных матчах.
