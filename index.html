Что менять в сборке по ситуации

Откуда данные. Винрейты и баны — Мифическая честь (25–49 звёзд) за 7 дней. Матчапы «+N п.п.» — насколько винрейт героя вырастает против конкретного врага по ранговым играм всех рангов. Источник — mlbbhub.
Золото и опыт. Если соперник выбран, оценка = (винрейт героя − 50) + матчап против соперника по статистике. Контрпик по механике без статистики получает +1, пара без статистики −0,5. «≈X% побед» = винрейт героя + матчап. Если соперник не выбран, оценка = (винрейт − 50) минус самый сильный ещё не забаненный контрпик с этой же линии: враг может взять его позже.
План на матчап. Начало и середина игры взяты из разобранной вручную пары, а если её нет — из статистики винрейта по стадиям игры (до 10, 10–16 и после 16 минуты) у обоих героев.
Роум. Восемь сильнейших роумеров патча по винрейту на Мифической чести. Оценка = половина разницы винрейта с 50% плюс бонус за отмеченную ситуацию: все восемь и так сильные, поэтому решает то, кто подходит под драфт. Если все восемь в бане, показан следующий по силе.
Баны. Список отсортирован по угрозе = (винрейт − 50) + бан-рейт / 20. У героев, которых банят очень часто, винрейт посчитан по меньшему числу игр.
Сборки. Базовый порядок закупки на всю игру, названия как в русской версии. Сборки части героев опыта шаблонные: сверяй с рекомендуемыми в игре.
Значки. Кружки с буквами и значки предметов нарисованы для этой страницы: красный — физический урон, фиолетовый — магия, зелёный — защита, золотой — ботинки. Это не игровые иконки.
