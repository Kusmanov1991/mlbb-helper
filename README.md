# MLBB Helper

Помощник для драфта в Mobile Legends: Bang Bang. Открываешь на втором телефоне во время пика и сразу видишь, кого брать и что покупать.

**Сайт:** https://kusmanov1991.github.io/mlbb-helper/

## Что умеет сейчас

- **Золото и опыт:** выбираешь соперника по линии и получаешь только прямых контрпиков к нему, с планом на матчап, комбо и сборкой на всю игру. Если прямого контрпика нет или соперник ещё не известен, страница показывает сильнейших героев патча на этой линии.
- **Роум:** сильнейшие роумеры патча. Отмечаешь ситуацию в драфте («у врага убийцы», «у нас нет танка» и т. п.) и получаешь того, кто подходит лучше всего.
- **Баны:** кого банить на Мифической чести. Отмеченные баны убираются из советов.

## Планы

Проект развивается. Дальше:

- автоматическое обновление данных после каждого патча;
- сборки топ-игроков вместо шаблонных;
- свой пул героев в рекомендациях;
- вернуть мид и лес, когда для них будет такой же подробный разбор.

## Данные

Статистика матчапов, винрейты и баны: [mlbbhub.com](https://mlbbhub.com). Mobile Legends: Bang Bang и все игровые материалы принадлежат Moonton.
